# A 的分支接入说明

本分支从共享 main 接入 A 已完成的 K-means/GMM、实验运行、画像及分群比较工具。保留 C 的谱聚类、现有清洗代码和原始数据文件。本次不提交个人报告、报告素材、汇报大纲、讲稿或 PDF，也不提交本地虚拟环境和 ZIP 交付包。

## 当前可使用的内容

- 两种算法统一返回标签、中心、GMM 概率、运行状态和拟合时间，不自行预处理。
- 实验入口支持 baseline、parameters、ablation，记录输入哈希、参数、种子、依赖版本和失败状态。
- 分析工具按 CustomerID 关联原始六特征；K-means 距离使用实际拟合矩阵，GMM 分析使用已保存的概率。
- 分群比较处理标签编号置换，输出交叉表、匹配重合比例、ARI 和 NMI；这些不是分类准确率。
- results/smoke/a_framework_check_v2 是历史回归夹具，原始尺度、300 位客户。其原有清单用于追溯当时的运行，不表示本分支已取得正式结果。

安装和完整测试命令见 README。requirements-algorithms.txt 引用共享 requirements.txt，使用仓库已有的 scikit-learn 和 SciPy 版本，另加入绘图和线程限制依赖。

## 当前接入状态与后续协调

已合入 C 的 preprocessing/feature_scaling.py，正式入口直接调用 load_customer_features 取得 CustomerID 和 X，不要求 C 导出新 CSV。A 自动记录来源、矩阵快照与代码版本。

正式实验按 C 当前入口对全量客户计算 Silhouette、DB、CH；全组最终指标函数、DBSCAN 噪声点处理、线程数与计时仍由 C 统一整合。本轮只对 A 的两种算法作结论。特征对照先完成 RFM 与六特征两组，最终分工仍与 B 对齐。

当前完成 78 次全客户运行及画像、分群比较，说明见 docs/a_experiment_results.md。个人报告和讲稿继续留在仓库之外。
